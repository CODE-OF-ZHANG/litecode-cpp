# Phase 1 Infrastructure: Project Directory Structure + CMake Build

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Set up the CMake build system and project directory structure so that `cmake --build build` produces a working executable that links all required dependencies.

**Architecture:** Single-target flat build — one `litecode` executable, all application code as header-only files included from `src/main.cpp`. Dependencies via FetchContent (cpp-httplib, jwt-cpp, nlohmann/json, zlib) and local find_package (mysql-connector-c++, OpenSSL). bcrypt bundled as C source files.

**Tech Stack:** C++17, CMake ≥ 3.15, cpp-httplib v0.18.3, jwt-cpp v0.7.0, nlohmann/json v3.11.3, zlib v1.3.1, mysql-connector-c++ 9.7.0, OpenSSL 3.x, OpenBSD bcrypt (rg3/bcrypt)

## Global Constraints

- C++17 standard required (`CMAKE_CXX_STANDARD 17`)
- C compiler also required (bcrypt is C source)
- Windows primary platform; local dependencies at `D:\GitHub_CODE\mysql-connector-c++-9.7.0-winx64` and `D:\GitHub_CODE\OpenSSL-Win64`
- All header-only libraries and zlib fetched via CMake FetchContent (no vcpkg)
- bcrypt sources bundled in `src/auth/bcrypt/` — no external library dependency
- Project namespace: `litecode`
- Build output to `${CMAKE_BINARY_DIR}/bin`

- [ ] **Step 1: Create `src/auth/bcrypt/blf.h`**

This is the Blowfish cipher header from OpenBSD, adapted for cross-platform use:

```c
/* $OpenBSD: blf.h,v 1.8 2021/10/24 21:24:20 mglocker Exp $ */
/*
 * Blowfish - a fast encryption routine ...
 * Public domain license — see original OpenBSD source for details.
 * Adapted for LiteCode-CPP cross-platform use.
 */
#ifndef BLF_H
#define BLF_H

#include <stdint.h>

/* Blowfish context */
typedef struct blf_ctx {
    uint32_t S[4][256];
    uint32_t P[18];
} blf_ctx;

/* Raw Blowfish functions */
void Blowfish_enc(blf_ctx *c, uint32_t *x, uint16_t klen);
void Blowfish_dec(blf_ctx *c, uint32_t *x, uint16_t klen);
void Blowfish_initstate(blf_ctx *c);

/* Standard Blowfish key schedule */
void Blowfish_expandstate(blf_ctx *c, const uint8_t *data, uint16_t databytes,
                          const uint8_t *key, uint16_t keybytes);
void Blowfish_expand0state(blf_ctx *c, const uint8_t *key, uint16_t keybytes);

/* BCrypt key schedule */
void Blowfish_expandstate(blf_ctx *c, const uint8_t *data, uint16_t databytes,
                          const uint8_t *key, uint16_t keybytes);
void Blowfish_expand0state(blf_ctx *c, const uint8_t *key, uint16_t keybytes);

/* BCrypt passphrase hash */
void blf_enc(blf_ctx *c, uint32_t *data, uint16_t blocks);
void blf_dec(blf_ctx *c, uint32_t *data, uint16_t blocks);

#endif /* BLF_H */
```

- [ ] **Step 3: Create `src/auth/bcrypt/bcrypt.h`**

The bcrypt public API header, adapted for cross-platform use:

```c
#ifndef BCRYPT_H
#define BCRYPT_H

/*
 * bcrypt password hashing
 * Adapted from OpenBSD for cross-platform use.
 * BSD-2-Clause License.
 */

#ifdef __cplusplus
extern "C" {
#endif

#define BCRYPT_HASHSIZE 64
#define BCRYPT_GENSALT_OUTPUT_SIZE 32

/* Generate a salt for bcrypt hashing.
 * workfactor: cost parameter (4-31, default 12)
 * output: buffer of at least BCRYPT_GENSALT_OUTPUT_SIZE bytes
 * Returns 0 on success, non-zero on error.
 */
int bcrypt_gensalt(int workfactor, char output[BCRYPT_GENSALT_OUTPUT_SIZE]);

/* Hash a password with the given salt.
 * key:     password to hash
 * salt:    salt generated by bcrypt_gensalt (or valid bcrypt salt string)
 * output:  buffer of at least BCRYPT_HASHSIZE bytes
 * Returns 0 on success, non-zero on error.
 */
int bcrypt_hashpass(const char *key, const char *salt,
                    char output[BCRYPT_HASHSIZE]);

/* Verify a password against a stored hash.
 * key:  password to verify
 * hash: stored bcrypt hash
 * Returns 0 if password matches, non-zero otherwise.
 */
int bcrypt_checkpass(const char *key, const char *hash);

#ifdef __cplusplus
}
#endif

#endif /* BCRYPT_H */
```

- [ ] **Step 4: Create `src/auth/bcrypt/bcrypt.c`**

The bcrypt implementation adapted from OpenBSD/rg3, with these key changes for Windows/MSVC compatibility:
- Replace `arc4random_buf` with a portable random generator using `BCryptGenRandom` on Windows or `/dev/urandom` on Linux/macOS
- Use `bcrypt_hashpass` naming (OpenBSD uses `bcrypt_hashpw` but the rg3 library standardizes on `bcrypt_hashpass`)
- No `<sys/types.h>`, use `<stdint.h>` instead
- Include path uses `"blf.h"` and `"bcrypt.h"` (local includes)

The file is ~200 lines and contains:
- `bcrypt_gensalt()` — generates a bcrypt salt string
- `bcrypt_hashpass()` — hashes a password with a salt
- `bcrypt_checkpass()` — verifies a password against a hash
- `encode_base64()` / `decode_base64()` — bcrypt's custom base64 encoding
- Portable `secure_random()` function for salt generation

### Task 2: Write `password_hash.h` — C++ bcrypt wrapper

**Files:**
- Create: `src/auth/password_hash.h`

**Interfaces:**
- Consumes: `bcrypt.h` functions (`bcrypt_gensalt`, `bcrypt_hashpass`, `bcrypt_checkpass`)
- Produces: `litecode::password_hash(password) -> string`, `litecode::password_verify(password, hash) -> bool`

- [ ] **Step 1: Create `src/auth/password_hash.h`**

```cpp
#pragma once

#include <string>
#include "bcrypt.h" // C interface from src/auth/bcrypt/bcrypt.h

namespace litecode {

/// Generate a bcrypt hash for a password.
/// Uses cost factor 12 (4096 iterations) by default.
/// @param password  The plaintext password to hash.
/// @return          The bcrypt hash string (e.g., "$2b$12$...").
inline std::string password_hash(const std::string& password) {
    char salt[BCRYPT_GENSALT_OUTPUT_SIZE];
    if (bcrypt_gensalt(12, salt) != 0) {
        return "";
    }

    char hash[BCRYPT_HASHSIZE];
    if (bcrypt_hashpass(password.c_str(), salt, hash) != 0) {
        return "";
    }

    return std::string(hash);
}

/// Verify a password against a bcrypt hash.
/// @param password  The plaintext password to check.
/// @param hash       The stored bcrypt hash string.
/// @return           true if the password matches, false otherwise.
inline bool password_verify(const std::string& password, const std::string& hash) {
    return bcrypt_checkpass(password.c_str(), hash.c_str()) == 0;
}

} // namespace litecode
```

```cmake
cmake_minimum_required(VERSION 3.15)
project(litecode LANGUAGES C CXX)

set(CMAKE_CXX_STANDARD 17)
set(CMAKE_CXX_STANDARD_REQUIRED ON)
set(CMAKE_CXX_EXTENSIONS OFF)

# ─── Build output ───
set(CMAKE_RUNTIME_OUTPUT_DIRECTORY ${CMAKE_BINARY_DIR}/bin)

# ─── Local dependency paths (Windows) ───
# Override with -DMYSQL_CONNECTOR_DIR=... -DOPENSSL_ROOT_DIR=...
set(MYSQL_CONNECTOR_DIR "D:/GitHub_CODE/mysql-connector-c++-9.7.0-winx64"
    CACHE PATH "Path to mysql-connector-c++ installation")
set(OPENSSL_ROOT_DIR "D:/GitHub_CODE/OpenSSL-Win64"
    CACHE PATH "Path to OpenSSL installation")

# ─── FetchContent: header-only libraries + zlib ───
include(FetchContent)

# cpp-httplib
FetchContent_Declare(httplib
    GIT_REPOSITORY https://github.com/yhirose/cpp-httplib.git
    GIT_TAG        v0.18.3)
FetchContent_MakeAvailable(httplib)

# jwt-cpp
FetchContent_Declare(jwt-cpp
    GIT_REPOSITORY https://github.com/Thalhammer/jwt-cpp.git
    GIT_TAG        v0.7.0)
FetchContent_MakeAvailable(jwt-cpp)

# nlohmann/json
FetchContent_Declare(json
    GIT_REPOSITORY https://github.com/nlohmann/json.git
    GIT_TAG        v3.11.3)
FetchContent_MakeAvailable(json)

# zlib
FetchContent_Declare(zlib
    GIT_REPOSITORY https://github.com/madler/zlib.git
    GIT_TAG        v1.3.1)
FetchContent_MakeAvailable(zlib)

# ─── find_package: local prebuilt dependencies ───
find_package(OpenSSL REQUIRED)
find_package(mysql-concpp CONFIG REQUIRED
    HINTS ${MYSQL_CONNECTOR_DIR})

# ─── Main executable ───
add_executable(litecode
    src/main.cpp
    src/auth/bcrypt/bcrypt.c
    src/auth/bcrypt/blf.c)

target_include_directories(litecode PRIVATE
    ${CMAKE_SOURCE_DIR}/src
    ${CMAKE_SOURCE_DIR}/src/auth/bcrypt)

target_link_libraries(litecode PRIVATE
    httplib::httplib
    jwt-cpp::jwt-cpp
    nlohmann_json::nlohmann_json
    ZLIB::ZLIB
    OpenSSL::SSL
    OpenSSL::Crypto
    mysql::concpp)

# ─── Build type default ───
if(NOT CMAKE_BUILD_TYPE)
    set(CMAKE_BUILD_TYPE Release CACHE STRING "" FORCE)
endif()
```
